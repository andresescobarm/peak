# PEAK

Sistema de análisis de video de futbolistas, empezando por centrodelanteros (9). Analiza los movimientos del jugador marcado respecto de compañeros y rivales, y sus movimientos finos (perfilarse, controlar, saltar, driblar, definir), para producir una rúbrica de debilidades y un plan de entrenamiento.
